# Szablony projektów DaVinci Resolve

Umieść w tym katalogu wzorcowy plik `.drp` (wyeksportowany z DaVinci Resolve:
**File → Export Project**) i wskaż jego ścieżkę w ustawieniach aplikacji.

Aplikacja skopiuje ten plik do folderu `DaVinci/` nowego projektu i nada mu nazwę
projektu. Sam plik `.drp` nie jest generowany od zera, ponieważ format DaVinci Resolve
nie jest publicznie udokumentowany.

Format `.drp` to binarny plik specyficzny dla DaVinci Resolve — nie próbuj go ręcznie
edytować w edytorze tekstowym.
